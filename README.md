# 🚀 Harsh Gupta — Portfolio

A modern, responsive developer portfolio built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion** — featuring 3D animations, smooth transitions, and a clean dark UI.

![Portfolio Preview](/.github/images/img_main.png)

---

## ✨ Features

- ⚡ Built with **Next.js 14** (App Router)
- 🎨 Styled with **Tailwind CSS**
- 🎞️ Smooth animations via **Framer Motion**
- 🌌 Animated star background
- 📱 Fully **responsive** on all devices
- 🔠 Custom fonts — **Raleway**, **Orbitron**, **Space Grotesk**
- 🧩 Modular component architecture

## 📂 Project Structure

```
├── app/
│   ├── layout.tsx        # Root layout with fonts & navbar
│   ├── page.tsx          # Home page
│   └── globals.css       # Global styles
├── components/
│   ├── main/             # Page-level sections
│   │   ├── navbar.tsx
│   │   ├── hero.tsx
│   │   ├── skills.tsx
│   │   ├── projects.tsx
│   │   ├── encryption.tsx
│   │   └── footer.tsx
│   └── sub/              # Reusable sub-components
│       ├── hero-content.tsx
│       └── project-card.tsx
├── constants/
│   └── index.ts          # All data (projects, skills, socials)
└── public/               # Static assets
```

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Harsh2126/portpolio.git
cd portpolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
